# Daily symbolic color guidance

This is a product heuristic, not a full BaZi useful-element recalculation and not evidence that clothing colors change outcomes. It never changes calendar scores. No random or date-based color rotation is used.

## Eligibility

- Display only for a selected reading below 50, with a daily elemental caution contributor.
- Omit special/uncertain chart patterns and cases with no eligible candidate.
- Candidates must already be primary/supportive in the natal assessment; exclude caution, neutral and unresolved assessments.
- Do not infer usefulness from an absent or low-count element.

## Selection

1. Aggregate caution elements in the day stem and branch using the calendar weights 1 and 0.7. These are scoring contributions, not a complete measure of element strength.
2. Target the largest negative elemental contributor; a tie uses input order.
3. Exclude candidates that generate any other daily caution element.
4. Offer every eligible element produced by the target (draining) or controlling the target as an equally styled alternative, with its own reason. Deduplicate elements; display order is not a ranking.
5. If neither exists, return no recommendation. Do not silently target a smaller contributor instead.

The filtering is an explicit application heuristic, not a universally established BaZi rule. No preference between draining and controlling is asserted. It does not evaluate transformations, hidden stems, seasonal interactions or the relative strength needed for effective control. The explanation is about the five-element relationship, not a claim that the selected color remedies a clash.

Cycle reference: Joey Yap, The Three Cycles, https://www.joeyyap.com/notes/rfs/Real_Feng_Shui.pdf . This supports generating, weakening and controlling relationships, not the application ranking or efficacy of color remedies.

For the default strong Earth example, daily Fire offers supportive Water (black); daily Earth offers both primary Metal (white) and supportive Wood (green). Wood is excluded if daily caution Fire is also present because Wood generates Fire. Users may choose one option, not accumulate all colors. Colors may legitimately repeat.
