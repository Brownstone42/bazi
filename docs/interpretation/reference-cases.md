# Reference cases สำหรับ Strength Rule Engine

สถานะ: Candidate set  
เวอร์ชัน: 0.1.0

ชุดนี้ประกอบด้วยดวงอ้างอิงตั้งต้น 30 เคส สร้างจาก `@openfate/bazi-engine` ภายใต้นโยบายเดียวกับเว็บ:

- ใช้เวลาท้องถิ่นตาม timezone
- ไม่ใช้เวลาสุริยะแท้ เพราะไม่มี longitude
- เปลี่ยนวันเวลา 23:00

## จุดประสงค์

- ครอบคลุมดิถีทั้งห้าธาตุ
- ครอบคลุมฤดูกาลทั้งสี่
- มีเดือนดิน 辰 戌 丑 未
- มีกรณีก่อน/หลัง 23:00
- มีกรณีใกล้ลิบชุน
- มี timezone นอกประเทศไทยและ DST

## สถานะผลที่คาดหวัง

ทุกเคสมีคำตอบตั้งต้นด้าน `strengthLevel`, `patternType`, `用神`, `喜神` และ `structureClarity` พร้อมเหตุผลอย่างน้อยสองข้อ โดยใช้สถานะ `baseline_hypothesis`

สถานะนี้หมายถึงเป็นคำตอบที่ใช้ตั้งต้นพัฒนาและทดสอบความสอดคล้องของ Rule Engine ยังไม่ถือว่าได้รับการยืนยันจากผู้เชี่ยวชาญอิสระ เคสที่อาจเป็นโครงสร้างพิเศษจะไม่กำหนด用神และ喜神 เพื่อไม่ให้ระบบฟันธงเกินหลักฐาน

## การสร้าง snapshot

```bash
node scripts/build-reference-case-snapshot.mjs
```

สคริปต์จะพิมพ์ข้อมูลทั้ง 30 เคสออกมาเป็น JSON โดยไม่แก้ไฟล์ใด ๆ

## ขั้นตอนตรวจรับแต่ละเคส

1. ยืนยันสี่เสา
2. ระบุเดือนและสถานะตามฤดูกาลของดิถี
3. ระบุรากทุกตำแหน่งโดยไม่คิดซ้ำ
4. ระบุแรงสนับสนุน ระบาย และควบคุม
5. ตรวจการรวมและการแปลง
6. ตรวจสัญญาณโครงสร้างพิเศษ
7. สรุป strength level และทางเลือกที่ใกล้เคียง
8. เลือก用神/喜神เฉพาะเมื่อเป็นโครงสร้างปกติที่ชัดพอ
9. ระบุ structure clarity
10. เปลี่ยนสถานะจาก `baseline_hypothesis` เป็น `reviewed` เมื่อมีการตรวจอิสระ

## Definition of done

Reference set พร้อมใช้ตรึงน้ำหนักเมื่อ:

- ทั้ง 30 เคสมีสี่เสาที่ผ่านการยืนยัน
- ทั้ง 30 เคสมี evidence worksheet
- ไม่มีเคสใดใช้การนับธาตุอย่างเดียวเป็นเหตุผล
- เคสก้ำกึ่งเก็บผลทางเลือกไว้
- เคสโครงสร้างพิเศษไม่มี用神แบบฟันธง
- ผู้ตรวจลงชื่อและวันที่ตรวจครบทุกเคส
